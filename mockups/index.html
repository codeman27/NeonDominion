Neon Dominion — art direction

Chosen: A · Neon Grid, mobile-first. B and C are kept for reference. Each new game gets a random map; the seed lives under Advanced so a map can be shared or replayed.

A · Neon Grid — Mobile primary target

  • Full-screen map that auto-rotates in portrait (view only; map data is identical on every device)
  • One phase at a time in a bottom sheet: Draft → Attack → Fortify → Commit
  • Tap to draft; tap your territory, then a pulsing enemy to queue an attack. Chained attacks are supported
  • Names appear only when zoomed in; commanders, continents, and the log live in the ☰ drawer
  • Pinch/drag (or wheel) to zoom/pan, ⤢ to fit
